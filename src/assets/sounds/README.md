# Звуки дома

Короткие уютные сигналы для кликов, событий и итогов дня.

Имена файлов:

- `button-click.wav`
- `new-event.wav`
- `good-choice.wav`
- `neutral-choice.wav`
- `bad-choice.wav`
- `achievement.wav`
- `day-complete.wav`

Если файла нет, игра остаётся без этого звука и не показывает ошибок. В настройках звук можно выключить.
