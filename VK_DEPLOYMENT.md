# Публикация во ВКонтакте

Игра может работать как VK Mini App в режиме `vk`. Это не отдельная копия проекта: тот же код, другой `VITE_APP_MODE`.

VK Bridge на этапе разработки подключается только в этом режиме. Секретные ключи, service token и server access token в frontend класть нельзя.

## 1. Production build

```env
VITE_APP_MODE=vk
VITE_BASE_PATH=/
VITE_VK_APP_ID=YOUR_VK_APP_ID
```

Или используйте готовый файл `.env.vk` / `.env.vk.example`.

```bash
npm install
npm run build:vk
```

Обычная команда `npm run build` собирает текущий режим из `.env`. Для Mini Apps нужна именно vk-сборка.

Готовые файлы: `dist/`.

## 2. Размещение

Содержимое `dist/` должно быть доступно по публичному **HTTPS** URL.

Например:

```text
https://game.example.ru/
```

Не используйте `http://` для production. Localhost допустим только для разработки, если платформа это позволяет.

## 3. Кабинет VK

Нужно создать и настроить Mini App в кабинете разработчика ВКонтакте и получить ID приложения. Актуальные названия разделов кабинета смотрите в официальной документации VK Mini Apps — они могут меняться.

`VITE_VK_APP_ID` — публичный идентификатор. После регистрации подставьте реальный ID и пересоберите проект.

## 4. URL

В настройках приложения укажите публичный HTTPS URL игры (тот, с которого отдаётся `dist/`).

Если сервер выставляет строгий `Content-Security-Policy` или `X-Frame-Options`, это может мешать встраиванию Mini App. Такие заголовки настраиваются на сервере, не в коде игры.

## 5. Проверка

1. Открыть приложение через VK.
2. Убедиться, что Bridge инициализируется (нет бесконечного экрана «Василий открывает двери…»).
3. Пройти главную → знакомство → игру → итог.
4. Обновить WebView на событии и на экране результата: эффекты не должны начисляться повторно.
5. Если имя VK доступно — на главной должно быть приветствие. Если нет — игра всё равно запускается.
6. Кнопка «Поделиться результатом» появляется только если платформа поддерживает `VKWebAppShare`. Публикация не происходит без нажатия.

## Что игра не делает

- не просит доступ к друзьям, сообщениям, почте, телефону и стене;
- не хранит прогресс на сервере;
- не публикует посты автоматически;
- не подключает аналитику, платежи и рекламу.
